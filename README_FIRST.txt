CAR DEALER COMPANION by JJ's Mods
Version 0.45.0.0

WHAT THIS BUILD IS
- Release-ready baseline for Car Dealer Companion.
- Read-only helper display for Car Dealer Simulator.
- Cars, Inventory, Parts and Contracts use live game data.
- Automation and AutoFleet + Dealerships are reserved as Coming Soon pages.
- F1 is the Companion show/focus/hide hotkey.

REQUIREMENT
- UE4SS must already be installed for Car Dealer Simulator.

INSTALL
1. Extract the entire ZIP to a normal folder.
2. Run INSTALL.cmd.
3. Start Car Dealer Simulator.
4. Press F1 to show/focus/hide the Companion.

UE4SS MOD ACTIVATION
- CarDealerInventoryReader uses enabled.txt (Enabled=true).
- The installer does not require CarDealerInventoryReader in Mods\mods.txt.

RUNTIME VISUALS
- Vehicle photos and supported UI icons are generated/read from the player's own installed game at runtime and cached locally.
- The release ZIP does not bundle extracted Car Dealer Simulator artwork.

UNINSTALL
- Run UNINSTALL.cmd.
- Companion Personal Cars/save-scoped Companion data are preserved.
- UE4SS itself is left untouched.
